# vim wizard ~ yank&slash ~

日本語 | [English](README.md)

VimとNeovimで遊べる、テキストを編集して攻略するダンジョンゲーム。
カーソルが主人公で、マップの文字そのものを切り取ったり貼り付けたりできる。
壁をコピーして追ってくる敵を止め、鍵を拾って地下深くへ進もう。

## 起動と言語選択

リポジトリを取得し、そのディレクトリから起動する。

```sh
git clone https://github.com/0x6d61/vim-wizard.git
cd vim-wizard
```

```sh
vim -Nu NONE -n --cmd 'set runtimepath^=.' \
  -c 'runtime plugin/yank_and_slash.vim' -c VimWizard

# Neovimの場合
nvim -u NONE -n --cmd 'set runtimepath^=.' \
  -c 'runtime plugin/yank_and_slash.vim' -c VimWizard
```

タイトル画面で「日本語」か「English」を選び、Enterでゲームを始める。
選択には `j` / `k`、上下矢印、または `1` / `2` を使う。
初期選択は日本語。
起動前に `let g:vim_wizard_language = 'en'` を設定すると、英語を初期選択にできる。

既存のVimから起動する場合は、このディレクトリを `runtimepath` に追加し、`runtime plugin/yank_and_slash.vim` を実行してから `:VimWizard` を実行する。
以前の `:YankAndSlash` も使える。

ゲーム中に `?` を押すと、選択した言語で基本操作の一覧が開く。
移動、削除、ヤンク、貼り付けと、`3w` や `2dd` の組み合わせ例を載せている。
通常のVimで使う入力や保存の操作は、ゲーム外の参考情報として別の欄にまとめている。

説明画面は `j` / `k` でスクロールし、`Ctrl-d` / `Ctrl-u` で半画面ずつ進める。
`gg` / `G` で先頭や末尾へ移動できる。
`q` またはEscで元の位置に戻り、説明を読んでいる間はターンが進まない。

## マップの読み方

| 表示 | 意味 |
| --- | --- |
| 強調表示されたカーソル | 主人公 |
| `·` | 床。元の `.` と空白を同じ見た目で表示する |
| `#` と `\|` | 壁。敵を止める |
| `r` | 追ってくる敵 |
| `k` | 鍵 |
| `$` | 金貨 |
| `>` | 次の階への階段 |

床は隙間のない `·` の並びで表示する。
内部の空白は単語の区切りとして残してあるので、`w` や `b` の移動はそのまま使える。
主人公のいる1マスだけは元の文字を強調表示する。
壁を水色、敵を赤、鍵と金貨を黄色、階段を緑で表示する。
上部の説明欄にはHP、MP、持ち物、ターン数、操作ガイドが表示される。
説明欄はマップとは別なので、`dd` や `yy` の対象にはならない。

## 敵から逃げて地下へ進む

鍵 `k` の上に止まると鍵を拾える。
鍵を持って階段 `>` に到達すると次の階に進む。
その際、最大HPと最大MPがそれぞれランダムに1〜9増え、HPは3と最大HPの増加分だけ回復し、MPは全回復する。
次の階ではターン数が0に戻る。
階層はランダムに生成され続け、最終階はない。
金貨もその上に止まると拾えるが、消しただけでは手に入らない。

1操作が終わると、敵が1文字分か1行分近づく。
敵は壁を迂回し、移動後に主人公と同じ場所か上下左右の隣にいると1ダメージを与える。
道がなければその場で待つ。
他の敵、鍵、金貨、出口の上には移動しない。
さらに各階で5ターンごとに敵が1体増える。
主人公から離れた、到達可能な床に現れ、次のターンから動き始める。
出現中の敵は最大24体で、階を移動すると出現までのターン数もリセットされる。

回数指定を含む `3w` も1ターンで、ヤンクや移動に失敗した操作でも1ターン進む。
考えている間や、`f` の次の文字を入力するまでの間には敵は動かない。

## 壁をコピーして道を変える

壁の行を `yy` でコピーし、`p` で貼り付けると新しい防壁になる。
`dd` で壁の行を切り取れば道が開く。
主人公はVimの移動操作で壁を越えられ、壁の上にいる間は敵の攻撃を受けない。
現在の試作品では敵は壁を壊さない。

`x`、`dw`、`dd` で敵の文字を消すと倒せる。
ただし、敵を含む文字列を貼り付けると敵も復活する。
編集はVim本来の動作なので、行を削除すれば下の地形も上に詰まる。

## 削除に使う魔力

`x` と `dw` は削除量に応じてMPを消費する。
消した文字8個ごとに1MP、敵1体ごとに1MP、壁4個ごとに1MPを合計する。
文字数には改行を含め、それぞれ端数を切り上げる。

たとえば敵1体を `x` で倒すと2MP。
`dd` は敵の数や削除する行数にかかわらず、1操作で8MPを消費する。
`5dd` でも合計8MP。
MPが足りない操作は取り消され、地形、レジスタ、ターン数は変わらない。

金貨はゲーム中に `S` で開ける店で使う。
HP回復薬（金貨3枚、HPを4回復）、MP回復薬（金貨3枚、MPを5回復）、無料攻撃の巻物（金貨5枚）を各階で1個ずつ買える。
巻物は次にMP消費が発生する削除操作を1回無料にする。
店の在庫は次の階で補充される。
買い物中はターンが進まず、`q` またはEscで戻れる。
貼り付けて増やした金貨も拾って使える。

MPの初期値は10で、最大MPは階層移動で増える。
通常の移動に3回成功すると1MP回復し、次の階では全回復する。
1マスの移動でも `3w` でも移動1回と数える。
その場で移動に失敗した場合や、ヤンク、貼り付けでは回復しない。

`f`、`F`、`t`、`T` で移動に成功すると、距離にかかわらず1MPを消費する。
MPが0でも移動できるが、そのターンは敵が通常の2倍動き、攻撃も2回受ける可能性がある。
対象の文字が見つからず移動しなかった場合、MPは消費しない。

## 攻撃と建築の演出

`x` や `dw` で敵を倒すと、倒した場所に火花が散る。
`dd` では消した行に横一閃が走り、複数体を倒すと撃破数を大きく表示する。
`p` や `P` で壁を貼り付けると、その壁が発光し、「防壁召喚！」と表示される。
説明欄には今回の冒険で倒した敵の合計も表示する。

演出は通常約0.25秒、複数撃破では約0.4秒で消える。
演出中でも次の操作を入力できる。
移動、巻き戻し、再挑戦、ヘルプへの切り替えやウィンドウの移動で演出は消える。
演出の文字はマップとは別に表示するため、ヤンクした内容には混ざらない。

MP不足で取り消した攻撃には演出が付かず、撃破数も増えない。
`u` で戻した場合は撃破数も元に戻る。
演出を無効にしたい場合は `let g:vim_wizard_effects = 0` を設定する。
撃破メッセージと合計の表示はそのまま残る。

## 対応する操作

| 操作 | キー |
| --- | --- |
| 移動 | `h j k l`、`w b e`、`0 ^ $`、`gg G` |
| 指定した文字へ移動 | `f F t T` のあとに文字。`; ,` で繰り返す |
| 削除 | `x dw dd` |
| コピーと貼り付け | `yy p P` |
| 1ターン巻き戻す | `u` |
| 新しいマップで最初から | `R` |
| 説明 | `?` |
| 店 | `S` |
| 日本語と英語の切り替え | `L` |
| ゲームを閉じる | `q` |

`u` は地形、敵の位置、HP、MP、持ち物、カーソル位置、番号付きレジスタと無名レジスタ、小さい削除用レジスタをまとめて戻す。
死亡後や次の階に進んだあとにも使え、最大100ターンを保持する。
言語選択は巻き戻さず、`L` で言語を切り替えてもターンは進まない。

`R` で新しいマップを作り直す。
生成時には開始地点から鍵、鍵から出口まで歩ける経路を確保するが、プレイ中の編集で鍵や出口を消すことはできる。
消してしまったときは `u` で戻すか、`p` で貼り戻そう。

## 試作品の範囲

マップは11行、39文字幅から始まり、編集によって形が変わる。
生成時の敵は階に応じて増え、上限は12体。
プレイ中の追加出現では最大24体まで増える。
開始地点から地形上の距離で9歩以上離して配置する。
金貨は各階に3枚。
同じマップを再現したい場合は、起動前に `let g:vim_wizard_seed = 42` を設定する。

ターン処理は上記の対応キーに限られ、それ以外のVimの移動操作ではターンを進めずに移動できる。
壁の複製や金貨の複製も許しており、得点を競うための制限はまだ設けていない。
必殺技ゲージは未実装。

削除とヤンクは通常のVimのレジスタを使う。
普段の編集で使っているレジスタを変えたくない場合は、上の起動コマンドで別のVimを開いて遊べる。

## 動作確認

```sh
vim -Nu NONE -i NONE -n -es -S tests/smoke.vim
vim -Nu NONE -i NONE -n -es -S tests/effects.vim
vim -Nu NONE -i NONE -n -es -S tests/teleport.vim
vim -Nu NONE -i NONE -n -es -S tests/spawn.vim
nvim --headless -u NONE -i NONE -n -S tests/smoke.vim
nvim --headless -u NONE -i NONE -n -S tests/effects.vim
nvim --headless -u NONE -i NONE -n -S tests/teleport.vim
nvim --headless -u NONE -i NONE -n -S tests/spawn.vim
```

言語選択、翻訳の切り替え、マップの到達性、敵の追跡、壁の迂回、建築、MPの消費と回復、巻き戻し、死亡、地下1000階への遷移を確認する。
演出については、途中の入力、タイマーの終了処理、複数撃破の数、攻撃の取り消し、マップとレジスタの保持を確認する。
